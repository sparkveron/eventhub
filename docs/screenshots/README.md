# Portfolio Screenshot Guide

No screenshots are committed yet. Capture the real running application at desktop
and mobile widths after replacing any personal usernames, email addresses, booking
references, and attendee data with safe demonstration data.

Recommended screenshots:

1. `01-home.png` - public home page with the hero and real published-event cards.
2. `02-event-discovery.png` - event catalogue with search, filters, active chips, and pagination.
3. `03-event-detail.png` - event details, ticket availability, quantity controls, and booking summary.
4. `04-organizer-dashboard.png` - organizer analytics, upcoming events, and recent bookings.
5. `05-event-management.png` - event performance, ticket management, and publishing controls.
6. `06-attendee-bookings.png` - attendee booking history with status treatments and detail modal.
7. `07-digital-ticket.png` - printable digital ticket using a non-personal attendee identity.

Before committing screenshots:

- Use test accounts and test-mode payments only.
- Remove or obscure real names, emails, booking references, and transaction identifiers.
- Do not show browser developer tools, environment files, tokens, or provider dashboards.
- Prefer consistent 1440px desktop captures plus one representative mobile view.
- Confirm uploaded event artwork is licensed or owned for portfolio use.
